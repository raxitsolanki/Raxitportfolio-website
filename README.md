# 🌐 Raxit Solanki Portfolio Website

## 📌 Project Overview

This is a modern, responsive personal portfolio website developed to showcase my skills, projects, education, and contact information. The website is designed with a clean UI and interactive animations to provide an engaging user experience.

It highlights my journey as a Python Developer and MCA student, along with real-world projects including Machine Learning and Web Development applications.

---

## 🚀 Features

* ✨ Modern UI with Glassmorphism Design
* 📱 Fully Responsive (Mobile + Desktop)
* 🎯 Smooth Scrolling Navigation
* ⌨️ Typing Animation Effect
* 🎨 Dynamic Theme with CSS Variables
* 📊 Skills Progress Bars with Animation
* 🧠 Project Filtering (ML / Web Apps)
* 📩 Contact Form Integration (EmailJS)
* 🔗 Social Media Integration (GitHub, LinkedIn)
* 📄 Resume Download Feature
* 🌌 Animated Particle Background

---

## 🛠️ Technologies Used

### Frontend:

* HTML5

## ⚙️ How to Run the Project

### ▶️ Method 1: Open Directly

1. Download or clone the repository
2. Open index.html in your browser

---

### ▶️ Method 2: Using Live Server

1. Open project in Visual Studio Code
2. Install Live Server extension
3. Right-click on index.html 
4. Click **Open with Live Server**
